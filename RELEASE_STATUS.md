# Public artifact status

Last reviewed: 2026-08-27.

The Camera Operator project page currently provides the camera-ready article,
its citation, and web-display versions of figures from that article.

The following artifacts are **not yet public**:

- training and inference code;
- model weights;
- BlockCam annotations or media.

The dataset release remains pending redistribution-rights review, a compatible
dataset license, public notices, and final archive approval. The article's CC BY
4.0 license does not grant permission for unreleased code, model weights,
datasets, source media, Unreal projects, Fab assets, or third-party components.

Artifact buttons on the project page will be activated only after the
corresponding package and license are available.
