# Public artifact status

Last reviewed: 2026-09-01.

The Camera Operator project currently provides:

- the camera-ready article, citation, and web-display versions of article figures;
- the public, synthetic-only [CameraOperator-BlockCam annotation dataset](https://huggingface.co/datasets/huuuuuuuuu/CameraOperator-BlockCam).

The following artifacts are **not yet public**:

- training and inference code;
- model checkpoints;
- REAL annotations or source media;
- Unreal/Fab projects, assets, and rendered media.

The public dataset contains 37,499 processed synthetic annotation-label records,
derived Parquet files, split metadata, and integrity checksums. It contains no
REAL records, Unreal/Fab assets, images, videos, audio, or project files. This
release is separately licensed under CC BY 4.0 and is not the paper's mixed
41K benchmark or a drop-in reproduction of the accepted-paper protocol.

The article's CC BY 4.0 license does not grant permission for unreleased code,
model weights, datasets, source media, Unreal projects, Fab assets, or
third-party components. Refer to each released artifact's own license and
notices.

Code and model buttons will be activated only after the corresponding package
and license are available.
